  - 在model_pool中有fallback逻辑(P0-8规范)

- **moa_gateway/routes/capability.py (行 445-495)** - 测试端点使用Mock:
  - @router.post("/v1/capability/embeddings") - 使用MockEmbeddingProvider
  - @router.post("/v1/capability/semantic-search") - 使用MockEmbeddingProvider
  - @router.post("/v1/capability/streaming") - 使用MockStreamingProvider
  - 这些端点默认返回mock前缀的响应,用于测试capability系统

### 1.2 Model Pool的Mock降级策略 (设计决策,非缺陷)
- **moa_gateway/model_pool.py**:
  - 行 441-474: _maybe_fallback_to_mock() 方法 - P0-8规范明确规定:
    - 仅在auth失败(401/403)时自动fallback到MockProvider
    - 500/timeout等临时错误不降级,保持真实provider
    - session级别临时保存,便于恢复
  - 行 248: api_key默认为"mock"的处理 - 用于占位符
  - 行 392: 检查provider_obj是否已是MockProvider - 防止重复降级

### 1.3 Server启动时的Mock检测 (信息日志)
- **moa_gateway/server.py (行 120-139)**:
  - 统计模型池中的mock模型数量
  - 警告用户"0个真实模型,全部使用MockProvider"
  - 显示"Mock模型"数量 - 用于启动诊断

### 结论
**无生产代码中残留的mock/stub/fake缺陷。** Mock都是合法的测试基础设施或设计上的降级机制。

## 2. Async正确性审查

### 2.1 Async/Await检查结果
**初步扫描:** 未发现明显的"coroutine never awaited"或RuntimeWarning

### 2.2 需要深度检查的高风险区域

1. **moa_gateway/mcp_server.py (行 93-114)**:
   - sync def _http_post() (行 93) - 使用 httpx.AsyncClient
   - sync def _http_get() (行 114) - 使用 httpx.AsyncClient
   - **需要验证:** 这些函数中是否都正确使用 sync with 和 wait

2. **moa_gateway/model_pool.py (行 593-656)**:
   - sync def call() 方法 - 调用外部provider
   - 行 656: logger.warning("mock fallback also failed: %s", e2) 
   - **需要验证:** 所有provider.chat() 调用是否都被 await

3. **moa_gateway/moa.py**:
   - 大量async def方法(行 221, 358, 398, 495等)
   - **需要验证:** _call_one_ref(), _call_with_fallback() 等核心调用

4. **moa_gateway/routes/ 中的异步handlers**:
   - 所有route handler都声明为 async
   - 需检查内部是否存在未await的协程调用

- moa_gateway/mcp_server.py 使用 httpx.AsyncClient

### 5.2 竞态条件分析

**发现的潜在竞态问题:**

1. **消息列表排序 (行 85-94)**:
   `python
   # 并发读取时可能出现不一致
   results.sort(key=lambda m: m.created_at, reverse=(order == "desc"))
   return results[:limit]
   `
   - 如果在读取和排序之间有新消息写入,可能返回不完整的结果
   - **风险等级**: P2 (低)

2. **Run对象搜索 (行 105-113)**:
   `python
   # 遍历所有thread目录查找run_id,可能遍历不到新建文件
   for thread_dir in runs_dir.iterdir():
       if thread_dir.is_dir():
           path = thread_dir / f"{run_id}.json"
   `
   - 如果在遍历过程中有新thread目录被创建,可能遍历不到
   - **风险等级**: P2 (低)

3. **目录创建竞态 (行 21-25, 80, 100, 129)**:
   `python
   folder.mkdir(parents=True, exist_ok=True)
   `
   - 使用了exist_ok=True,相对安全
   - **风险等级**: P3 (已缓解)
